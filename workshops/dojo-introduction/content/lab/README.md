# Dojo Introduction: the tour

Nothing here is a lab you have to finish. Everything the platform can do is running, and this terminal has the
tools for all four workshops. Pick anything.

- **Slides:** the platform tour, and every workshop's own slides, labs and cheat sheet, from the **Slides** button
  (or **Workshop Library**).
- **The tool tour:** [tools-tour.md](tools-tour.md), one short set of commands per capability.
- **The example repo:** `git clone http://git-server:3000/dojo-team/dojo-tour.git` (Forgejo asks for your account
  name and the password on your landing page; it is remembered for the rest of the session).

Whoever you are signed in as, `whoami` says so: `studentNN` for a student, the facilitator's name for the facilitator.
