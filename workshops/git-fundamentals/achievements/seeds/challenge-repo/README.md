# Challenge repo for {user}

Your own copy of the team repo, made for the Git Fundamentals challenges. Nobody else can
change it, so merge, branch and break things freely.

- `roster/team.yaml`: who is on the team and what they do.
- `config/settings.yaml`: the team's deploy settings.

Start a challenge with `dojo-challenge start c1` (it prints the goal), check it with
`dojo-check c1`, and get a fresh copy any time with `dojo-challenge reset c1`.
