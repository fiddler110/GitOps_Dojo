# Session 1 Materials Distribution Checklist

Use this checklist to prepare, distribute, and close out the Azure DevOps edition of Session 1.

## Materials and Owners

| Material                      | Audience                          | Owner       | Delivery location or link                                    |
| ----------------------------- | --------------------------------- | ----------- | ------------------------------------------------------------ |
| Pre-work checklist            | Attendees                         | Facilitator | `[PRE-WORK LINK]`                                            |
| Azure Repos sample repository | Attendees                         | Facilitator | `https://dev.azure.com/[ORGANIZATION]/[PROJECT]/_git/[REPO]` |
| Slide deck                    | Attendees                         | Facilitator | `[SLIDES LINK]`                                              |
| Cheat sheet                   | Attendees                         | Facilitator | `[CHEAT-SHEET LINK]`                                         |
| Lab instructions              | Attendees                         | Facilitator | `[LAB LINK]`                                                 |
| Facilitator guide             | Facilitator or backup facilitator | Facilitator | `[FACILITATOR GUIDE LINK]`                                   |
| Azure DevOps setup guide      | Facilitator or project admin      | Facilitator | `[SETUP GUIDE LINK]`                                         |
| Feedback survey               | Attendees                         | Facilitator | `[SURVEY LINK]`                                              |

## One Week Before

- [ ] Confirm the Azure DevOps organization, project, repository name, and default branch.
- [ ] Confirm attendees have Microsoft Entra/Azure DevOps access to the project.
- [ ] Confirm the sample repository contains the expected README, CONTRIBUTING guide, and `roster/team.yaml` file.
- [ ] Run the facilitator clone, branch, commit, push, pull request, and merge test.
- [ ] Confirm the pull request permissions and branch policies allow the planned lab.
- [ ] Decide where the deck, cheat sheet, and lab link will be posted.
- [ ] Identify a backup facilitator or support contact.

## Twenty-Four Hours Before

- [ ] Fill in the placeholders in [pre-work-checklist.md](pre-work-checklist.md).
- [ ] Send the pre-work checklist, sample repository URL, session date/time, and support contact.
- [ ] Send the calendar invite or confirm the meeting link.
- [ ] Publish the attendee-facing links in one place, such as Teams, Azure DevOps Wiki, or the meeting chat.
- [ ] Confirm the feedback survey is open and does not require facilitator-only permissions.

## Thirty Minutes Before

- [ ] Open the Azure DevOps project and sample repository.
- [ ] Open the local demo clone in VS Code or the chosen editor.
- [ ] Open the terminal at the repository root.
- [ ] Have the slide deck, cheat sheet, lab instructions, and backup-slide content ready.
- [ ] Copy the repository URL and attendee resource links so they can be pasted into chat quickly.
- [ ] Verify screen sharing, terminal font size, and browser sign-in.
- [ ] Confirm the sample branch or conflict demonstration is reset to the intended starting state.

## During the Session

- [ ] Share the repository URL before the hands-on lab begins.
- [ ] Remind attendees to use a personal branch and not commit directly to `main`.
- [ ] Share the cheat sheet before the first command exercise.
- [ ] Track unresolved access or authentication issues for follow-up.
- [ ] Keep the feedback survey link ready for the final two minutes.

## Immediately After

- [ ] Share the slide deck, cheat sheet, lab instructions, recording link, and survey.
- [ ] Thank attendees and state where follow-up questions should go.
- [ ] Note any attendee who could not complete the clone or pull request workflow.
- [ ] Preserve the sample repository in a clean state for the next cohort.

## Within Two Business Days

- [ ] Review survey responses and summarize the top three themes.
- [ ] Follow up on unresolved Azure DevOps access or authentication issues.
- [ ] Update [faq.md](faq.md) with questions that came up repeatedly.
- [ ] Update the slide outline or [backup-slide-content.md](backup-slide-content.md) for topics that needed more explanation.
- [ ] Record improvements in the next-session planning notes.
