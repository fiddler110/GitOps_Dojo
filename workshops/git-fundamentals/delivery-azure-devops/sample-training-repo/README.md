# Team Training Roster

Welcome to the **Team Training Roster** — a simple git sandbox for hands-on practice.

This repo is used in our **Git Fundamentals** lunch-and-learn session. It's a low-stakes, relatable space where everyone can practice the core git workflow: branching, committing, pushing, and opening pull requests.

## Quick Start

```bash
git clone <this-repo-url>
cd sample-training-repo
git checkout -b add-yourname
```

Then follow the steps in [CONTRIBUTING.md](CONTRIBUTING.md).

## What's Here

- **`roster/team.yaml`** — A simple list of team members and their roles.
- **`CONTRIBUTING.md`** — Instructions for adding yourself to the roster (and practicing git).
- **`README.md`** — This file.
